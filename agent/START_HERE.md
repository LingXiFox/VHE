# 给本地 Agent 的初始任务（直接执行，无需新开子代理）

你是 VHE 项目的工程执行 Agent。开始前阅读项目根目录 `AGENTS.md`、`docs/CHARTER.md`、`docs/PROTOCOL.md`、`docs/RESEARCH_LOG.md`、`docs/MILESTONES.md`。项目目标是 **机械音频张量 → 独立神经自然化 VHE → 同内容/同音高/尽量同音色的自然音频张量**。VHE 模型推理禁止读取歌词、音素、MIDI、speaker ID 和真人参考。

## 本轮任务：仅 P0 + P1 的前半程，先验证再训练

1. 检查现有仓库状态和本机环境（OS、Python、Git、GPU/CUDA/MPS 可用性），不要假设预装依赖。先阅读 `docs/PLATFORMS.md`，执行 `python -m vhe doctor --device auto`、`python -m vhe smoke --device auto`、`pytest -q`。按实际硬件额外显式测试 `cuda` / `mps`，记录设备状态和失败日志。测试与机械声 demo 失败必须保留错误日志，修复后复测。
2. 核实 `src/vhe/synth.py` 是谐波/共振峰**代理模型**而非真实声道物理模拟；听音并记录机械感、失真、音素串联问题；针对缺陷提出可测改进，但**不得把机械基线伪装成 VHE**。
3. 设计可插拔上游合成器接口 `VoiceTemplate + PhonemeSequence + PitchCurve + Timing → MechanicalTensor`，输入输出契约和单位清楚；当前 MVP 只能 a/i/u，不要谎称支持 yuan。
4. 构建 AISHELL-3 **本地目录适配器**：先只读取提供的数据路径，不自动下载。把汉字/拼音/音频/说话人 ID 映射成 manifest，SHA256 索引、错误统计、纯净训练/测试 split。若机器上未安装真实数据，使用合成**测试夹具**做解析器单测，并报告等待数据的阻塞；不能冒充真人数据。
5. 设计对齐管线：从授权真人语音获得音素时长、F0 和能量供**训练数据构建**，标记不可信对齐和 F0 缺失，不得静默丢弃。构对阶段可利用真人目标做分析，但最终 VHE 推理不得接收这些控制数据。
6. 实现导出配对样本索引的接口及数据质量报告；最少准备手工试听 20 对音频的审查表格模板。真实样本不可用时，只构建管线和单测，不训练。
7. 每个假设创建 `EXP-XXXX` 目录，记录成功和失败、命令、环境、seed、数据哈希。每完成一个可验证阶段进行 Git commit；不要创建远程、不要推送、不要选择新许可证。

## P0 完成条件

- `pytest -q` 全绿，Windows/本机 CPU 可运行；同种子 WAV SHA256 不变。
- 自然化 VHE 仍未训练，README 中明确报告。
- 实验记录器拒绝重复 ID，Git 忽略真实声音/训练产物。

## P1 半程完成条件

- 真实 AISHELL-3 数据存在：至少 20 条能通过解析+时间/音高质量校验，并有人工听音结果；无真实数据：单测完整，说明阻塞且不假装完成。
- 划分不泄漏 speaker，成对关系和数据来源可追溯。
- 最后输出：变更摘要、测试命令和实际结果、实验目录、问题清单、下一轮建议，不要说「应该可以」当作成功。

## 禁止事项

未完成 P1 验收前不要用全量数据启动 GPU 训练，不要拉取数十 GB 数据、不能自动改系统 CUDA 驱动或长期执行后台工作、不允许直接把真实人的音色用于公开克隆 Demo。

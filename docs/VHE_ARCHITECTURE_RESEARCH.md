# VHE 架构研究：从机械波形到自然波形的映射该怎么搭

本文件是 v0.1 架构的决策记录，不是文献综述，也不是「已实现即可用」的声明。所有数字要么来自本仓库实测（标注 EXP 编号），要么明确标注为估计/待测。

## 0. 结论摘要

- v0.1 采用**波形域残差 U-Net**：`y = x + f(x)`，`f` 输出层零初始化，因此初始状态严格等价于恒等映射（实测 `max|y-x| = 0.0`，EXP-0008）。
- 参数 1,001,089；实测感受野 1224 样本 ≈ 51.0 ms（24 kHz，−611/+612 样本），相当于 65 Hz 的 3.3 个周期、180 Hz 的 9.2 个周期。
- 输入输出契约不变：`[B,1,N] → [B,1,N]`，同采样率、同长度，不接受 F0/音素/说话人/参考音频。长度非 8 的倍数时用 reflect padding 补齐后裁回（实测 777/1000/24000/24013 全部原长返回）。
- **不能**据此宣称音色保持、说话人无关性或自然度；这些是 P2/P3 的待验证假设。

## 1. 问题定义

输入 `x`：机械合成器产出的单声道波形，典型缺陷是（a）激励过于理想，周期严格等长、无 jitter/shimmer；（b）缺少气声与摩擦噪声；（c）谐波衰减过快或过慢，听感「电子」；（d）段间过渡生硬。

目标 `y`：同一段话的自然录音，**音高曲线、时长、内容不变**，音色尽量保持。

三个必须承认的结构性事实：

1. **一对多**。同一机械输入对应无穷多自然实现：jitter 幅度、气声比例、共振峰微动都是随机的。用 L1/L2 学确定性映射，最优解是这些实现的**条件均值**，听感上就是「平滑/糊」，正是要避免的失败模式。v0.1 先接受这一点（确定性 baseline），随机性留给 P4（GAN / flow）。
2. **信息不足**。模型只能看到机械波形。凡是机械波形里不存在的信息（例如"这个词该读重音"），架构再大也学不到；强行要求模型改变，只会把错误引入音高/时长，违反契约。
3. **可测性有限**。现有指标（谱损失、F0 误差、能量轮廓）都只是代理，与听感的相关性未验证。文档里每个指标都必须写清「它看不见什么」。

## 2. 候选家族对比

| 方案 | 无外部条件 | 音色保持风险 | 时序/内容保持 | 算力（16 GB 笔记本 / MPS） | 主要失败模式 | 结论 |
|---|---|---|---|---|---|---|
| 波形残差 U-Net（本方案） | 天然满足（只吃波形） | 中：残差可能改写谱包络 | 好：等长、局部编辑、可加残差正则 | 低（1.0 M 参数） | 平均化、只改局部、长时韵律修不了 | **v0.1 采用** |
| 膨胀 TCN / WaveNet 式 | 满足 | 中 | 中：因果卷积引入固定延迟 | 中（感受野大但串行） | 相位/延迟对齐错误 | v0.2 分支候选 |
| GAN post-filter（WaveCycleGAN2 式） | 满足 | 高：判别器可驱动音色漂移 | 中 | 中高（判别器 + 多尺度） | 模式崩塌、训练不稳 | P4 |
| VAE/RAVE 潜空间 | 满足 | 高：潜空间重建本身丢音色 | 中 | 中 | 重建损失主导、细节丢失 | 不作为主路 |
| Diffusion / flow matching | 满足 | 中 | 中 | 高（多步采样） | 采样成本、MPS 支持不确定 | P4 候选 |
| 参数域（WORLD/PSOLA 分析→NN 改参数→重合成） | 需 F0/谱包络估计，噪声大 | **高**：重合成等于换激励，音色易变 | 差：时长/相位由重合成决定 | 低 | 通过换音色获得假自然度 | 仅作消融对照 |
| HiFi-GAN 式生成器（mel→波形） | 不满足（需要 mel） | — | — | — | 违反契约 | 排除 |

拒绝理由的要点：

- **diffusion/flow** 作为第一版不可取：24 kHz 下 1 s 音频即使 10 步采样也要 10 次全网络前向，MPS 上的算子覆盖率未验证；在还没有任何 baseline 数字之前引入它，会把「不work」归因不清。
- **参数域方案**最危险的地方不是精度，而是它可以**通过替换激励/谱包络伪造自然度**，从而掩盖音色保持问题（AGENTS.md 明令禁止）。它适合作为对照实验，用来量化「纯参数修正能走多远」。
- **HiFi-GAN / mel 条件生成**直接违反「唯一输入是机械音频」。

## 3. 为什么 v0.1 是残差 U-Net

1. **契约由结构保证**：只有 `x` 一个输入，没有旁路；输出 = 输入 + 编辑，长度/采样率天然一致。审查者可以只看 `forward` 就确认没有偷偷用别的条件。
2. **恒等起点可验证**：零初始化输出层让 step 0 的输出逐位等于输入（EXP-0008 实测 0.0），训练前后可以严格对照「模型到底改了什么」。
3. **感受野与目标伪影匹配**：51 ms 覆盖 3–9 个基音周期，足以观察周期结构（jitter/气声会改变自相关峰高）与音节内的谱包络变化；这是"嗡嗡声/干声"这类局部伪影所在的时间尺度。
4. **多尺度 skip 同时看细节与包络**：编码器 3 次下采样（24k→12k→6k→3k），瓶颈处的膨胀卷积用 1..32 的 dilation 覆盖约 1 s 的上下文统计（注意：**不是** 51 ms 感受野之外的直接通路，skip 只相加同尺度特征）。
5. **工程可移植**：仅 Conv1d/SiLU/Upsample，无自定义 CUDA 算子，FP32，MPS 实测与 CPU 的编辑差异 3.1e-6（EXP-0008），没有 float64。

被拒绝的替代细节：

- `ConvTranspose1d(stride=2)`：kernel 与 stride 不互质时脉冲响应出现周期性梳状结构，落在音频带内就是"加了一层嗡声"，而这正是要修的东西。改用 nearest 上采样 + Conv1d，并在 EXP-0008 里量它的脉冲响应而不是假设它干净。
- BatchNorm：batch 4–8、音频非平稳，统计量不可靠。
- LayerNorm over time：会把整句话的信息混进每一帧（泄漏未来），且与"只看局部"的假设冲突。
- 因果卷积：VHE 是离线处理，非因果带来的质量收益大于实时性损失；实时化是单独的工程任务，不在 v0.1 范围。

## 4. 结构细节（与 `src/vhe/model.py` 一致）

```
stem      Conv1d(1, 32, k=9, pad=4)
enc1      DilatedBlock(32,  d=1,2,4,8)              24 kHz
down1     Conv1d(32, 64, k=4, s=2, pad=1)           12 kHz
enc2      DilatedBlock(64,  d=1,2,4,8)
down2     Conv1d(64,128, k=4, s=2, pad=1)            6 kHz
enc3      DilatedBlock(128, d=1,2,4,8)
down3     Conv1d(128,128, k=4, s=2, pad=1)           3 kHz
mid       DilatedBlock(128, d=1,2,4,8,16,32)
up3       Upsample(2, nearest) + Conv1d(128,128,k=3,p=1);  + enc3
dec3      DilatedBlock(128, d=1,2,4,8)
up2       Upsample(2) + Conv1d(128,64,k=3,p=1);        + enc2
dec2      DilatedBlock(64, d=1,2,4,8)
up1       Upsample(2) + Conv1d(64,32,k=3,p=1);         + enc1
dec1      DilatedBlock(32, d=1,2,4,8)
head      Conv1d(32,1,k=9,p=4)，权重与 bias 全零
```

- `DilatedBlock` 内每次卷积都是 `x = x + SiLU(conv(x))`，无归一化。
- 长度：`pad = (8 - N % 8) % 8`，reflect 补齐；前向末尾裁回 `N`。
- 参数：1,001,089。实测感受野（脉冲影响区间，阈值为峰值 1e-6）：**左 611 / 右 612 样本，宽 1224 样本 = 51.0 ms**。

感受野公式自检：`stem 9 + enc1 30 + down1 3 = 42`；`enc2 30×2 = 60 → 102`；`down2 6 → 108`；`enc3 30×4 = 120 → 228`；`down3 12 → 240`；`mid 126×8 = 1008 → 1248`；解码侧与 head 只增加少量（实测 1224 与估算 1248 差 2%，差异来自 stride 边界取整与阈值截断）。

## 5. 已知局限（必须写进每次报告）

1. **不能修改长时韵律**：51 ms 感受野之外的重音、语调、语速、停顿分布都不在能力范围内；模型只能改局部音色与微结构。想改韵律就必须改架构（v0.2 的多尺度分支），而不是加大损失权重。
2. **确定性映射 → 平均化风险**：无隐变量、无对抗项，输出是 `x` 的确定性函数。典型失败是"谱变平滑、气声比例固定"，听起来像另一个模型而不是真人。
3. **音色保持未被验证**：残差结构只是让"不改"成为可表示解，不保证学到的解接近它。需要 P3 的跨模板/跨说话人对照与听测。
4. **相位无约束**：MRSTFT 只看幅度谱，模型可以把能量挪到错误相位上而不受惩罚，听感会变成"模糊/双声"。
5. **训练信号与目标伪影错配**：见 `docs/LOSS_DESIGN.md` §5，量化/嗡声类伪影在现有损失下几乎不被惩罚（实测 8-bit 量化的总损失增量仅 0.126，而其他失真为 1.6–2.4）。

## 6. 下一步（v0.2 及以后）

- **v0.2 双分支**：局部支路（同 v0.1）+ 全局支路（在 1.5 kHz 上 dilation 64/128，或直接对 8 kHz 降采样序列做自注意力），拼接受限的全局上下文；必须先做消融证明它确实改善韵律而不是只增加参数。
- **P4 随机性**：优先 flow matching（少步、稳定）而不是 GAN；判别器只作为辅助项并单独记录其失效模式。
- **P3 对照**：`ResidualUNet` vs `ResidualVHE`（小原型）vs 参数域重合成，三者用同一损失与同一数据，报告音高/时长/音色/听感四项。

## 7. 待验证假设（不得当作结论）

| 假设 | 证伪方式 | 当前状态 |
|---|---|---|
| 说话人无关（同一模型适配未见过的原创音色） | P3 用训练中从未出现的模板做测试，音色相似度不显著低于训练模板 | 未验证 |
| 音色保持 | 与输入对比的谱包络距离、听测 ABX | 未验证 |
| 自然度提升 | 盲测（真人 vs 机械 vs 输出），至少 10 名听者 | 未验证 |
| 内容不变 | 时长一致 + 能量轮廓相关 + 人工抽查音节 | 仅合成夹具 |

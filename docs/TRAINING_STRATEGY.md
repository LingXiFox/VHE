# VHE 训练策略

本文件描述**从零到第一次真实训练**的路径与判据。当前状态：P0 本机复现完成（`python -m vhe doctor/smoke` + 86 tests），P1 数据准备进行中（无 AISHELL-3 本地数据），**尚未进行任何真人数据训练**。

## 1. 数据

| 用途 | 数据 | 许可 | 本机状态 |
|---|---|---|---|
| 训练/验证 | AISHELL-3（218 说话人，约 85 h，44.1 kHz） | Apache-2.0（需自行下载） | **未下载**（AGENTS：不得自动拉取大型数据） |
| 合成对照 | `src/vhe/synth` 生成的机械音频 | 本项目 | 可用 |
| 单元测试 | 合成夹具 | 本项目 | 可用 |

- 下载前必须：确认许可条款、磁盘（原始 + 转码后约 100 GB 级）、确认不与 Git 混放（`data/` 在 .gitignore）。
- 采样率统一到 24 kHz（训练用），保留原始 44.1 kHz 副本用于重采样前后对照。
- **不得**把原始授权录音提交进 Git。

## 2. 成对数据构造（`src/vhe/data/pairing.py`）

```
真实录音 (24 kHz)
  → f0.py 提取 F0（YIN/CMND，已修：16/24/48 kHz × 65–880 Hz 误差 ≤0.01%）
  → segment.py 有声段检测（样本级精修，60 ms 停顿可分辨）
  → synth 用「同一 F0 曲线 + 同一音节切分」渲染机械版
  → 逐音节 RMS 匹配（峰值封顶 0.999，超出记 gain_limited_by_peak）
  → 产出 {real, mechanical, f0, segments, gains_db, issues}
```

已知限制（必须写进实验记录，不能当成功）：

1. **渲染后端只支持 a/i/u 三个元音**，辅音与闭塞靠静音/噪声近似 —— 机械版在辅音段与真人差距过大，这些帧会主导损失。P1 的下一步是让后端接受辅音/摩擦音参数，或者在训练时对辅音帧降权（需实验证明不是掩盖缺陷）。
2. F0 提取对**缺失基频**（200 + 4×400 Hz）会读成 400 Hz（EXP-0007 记录，未修）。这类帧需标记并在统计里单独报告。
3. 音节切分依赖能量门限，弱起音会被切开（EXP-0007 的 20 ms click 被丢弃即为边界的体现）。

## 3. Split 规则（硬约束）

- **同一段真人录音导出的机械/真人配对永远在同一 split**。
- 按 **speaker** 分组：AISHELL-3 的 218 个说话人中，先固定 180/19/19（train/val/test），写入 `data/splits.json` 并提交（只含 id，不含音频）。
- 原创模板（`src/vhe/synth` 的音色模板）作为 **test-only**，训练中绝不出现，用于验证"说话人无关"假设。
- 任何 split 变更都要新开实验编号并说明原因，不得悄悄改。

## 4. 课程（由小到大，每步都要有失败判据）

| 阶段 | 数据量 | 目的 | 通过判据 |
|---|---|---|---|
| S0 单批过拟合 | 1 条 1 s 片段，batch 4（复制） | 验证梯度/损失/设备正确 | 200 步内 total 降到初始的 20%，且残差非零 |
| S1 十条 | 10 条，各 1 s | 验证泛化不是靠记忆 | val total < S0 的 train total |
| S2 单说话人 | 1 说话人全部 | 验证同音色下的自然化上限 | val F0 RMSE < 30 cents，时长误差 < 5 ms |
| S3 多说话人 | 180 说话人 | 主训练 | 见 §6 |
| S4 跨模板 | 未见过模板 | 说话人无关性 | 音色相似度不显著低于 S2（统计检验，不是目测） |

S0–S1 只在本机 CPU/MPS 上跑，单次 < 10 分钟；S2 起才需要长训练，**必须先获得许可**。

## 5. 超参初值（未调，仅记录起点）

```
optimizer   AdamW(lr=2e-4, betas=(0.8, 0.99), weight_decay=1e-4)
schedule    cosine, 200 warmup steps
batch       4 × 1.0 s (24000 samples)     # 16 GB 笔记本可承受的上限待测
precision   FP32（MPS 禁 float64；CUDA 不用 fused ops）
clip        grad norm 5.0
```

这些数字来自同类波形生成工作的常见做法，**没有在本仓库验证过**，第一个 run 必须做 lr ∈ {1e-4, 2e-4, 3e-4} 的小扫。

## 6. 监控与停止条件

- 每个 epoch 记录：train/val 六个分项、总损失、梯度范数、学习率、吞吐（samples/s）、显存峰值。
- 每 N 步保存音频样本（固定 3 条 val + 3 条原创模板），并生成谱图对比图；音频存 `experiments/<EXP>/audio/`，不进 Git。
- **停止条件**：val total 连续 3 个 epoch 不降 → 停；出现 NaN/inf → 立即停并保留最后一个 checkpoint；F0 RMSE > 30 cents 或时长漂移 > 5 ms → 判定违约，停。
- 早停只看 val，不看 train。

## 7. 计算预算（待实测）

- 本机 macOS Apple Silicon（MPS）：`ResidualUNet` 1.0 M 参数、1 s 输入的前向/反向时间**尚未测量**（EXP-0008 只测了正确性，没有计时）。
- RTX 4090 Laptop 16 GB：机器不在本会话可用范围（用户明确不做 Windows CUDA），因此**不得**声称 CUDA 路径已验证。
- 训练前必须先用 S0 测出 step 时间，再估算 S3 的时长并写进实验记录；不允许"先跑起来再说"。

## 8. 记录规范（每个实验目录）

`experiments/EXP-XXXX/` 必须包含：`README.md`（假设、唯一变量、对照、数据分组、判据、结果、失败原因）、`metadata.json`（由 `tools/new_experiment.py` 创建，记录 commit/dirty、Python/PyTorch/CUDA/MPS/OS、依赖锁、种子、manifest 哈希、命令、输出哈希）、`logs/`、`checkpoints/`（不进 Git，只记哈希）。失败实验目录**永不删除**；纠正历史结论只能追加 errata。

## 9. 风险清单

1. **数据不存在/许可不清** → 阻塞，如实记录，不绕道用别人的预处理结果。
2. **成对数据质量**：辅音段渲染不可靠（见 §2.1），可能训练出"只改元音"的模型；需在 S2 后做一个"元音/辅音分段损失"消融。
3. **音色漂移**：残差项权重过低会让谱损失驱动音色改写；必须做权重扫并报告漂移量。
4. **过拟合小数据**：1.0 M 参数对 10 条 1 s 片段极易记住；S1 必须用未见片段验证。
5. **MPS 数值差异**：EXP-0008 实测 CPU/MPS 编辑差 3.1e-6（FP32），但训练 1e4 步后的发散未测；S2 起需同时报告两端 loss 曲线。

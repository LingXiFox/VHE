# EXP-0005 — 信号前端：有理数重采样、自相关 F0、能量分段

## 假设
80/147 多相 windowed-sinc 重采样器（44.1 kHz → 24 kHz）在 0.5–4 kHz 通带内增益偏差 ≤0.5 dB、对 15 kHz 分量衰减 ≥40 dB；归一化自相关 F0 跟踪在 100–400 Hz 合成信号上误差 ≤3%；能量谷分段能还原 4 个合成音节且不合并；所有分析失败必须作为计数 issue 暴露，不得静默过滤。

## 变量 / 对照组 / 数据划分
- 唯一实现变量：新写的 `src/vhe/data/{resample,f0,segment}.py`。
- 对照组（负对照）：`np.interp` 线性插值重采样，同样输入信号，用来证明多相 sinc 不是装饰。
- 数据：全部为合成信号（正弦、线性扫频、矩形突发）。**本机没有 AISHELL-3 语料，本实验没有任何真实语音结论**，见 `docs/DATA_POLICY.md`。
- 划分：本实验不涉及训练/验证/测试划分（纯信号处理）。

## 预注册通过/失败条件
1. 三种采样率（44100/16000/48000 → 24000）输出长度严格等于 `round(N*dst/src)`。
2. 0.5/1/2/4 kHz 通带增益偏差 ≤0.5 dB；15 kHz 残留 ≤ -40 dB。
3. 稳态 100/120/220/300/400 Hz 的 F0 相对误差 ≤3%，voiced ratio ≥0.9。
4. 100→400 Hz 扫频的平均相对误差 ≤3%，且轨迹单调上升。
5. 4 个 120 ms 突发被分为 4 段、全部判 voiced、无 error 级 issue。
6. 10 ms 点击不得成为音节，且必须以 `segment_too_short` 记录；纯静音必须以 `no_speech`（error）记录。
7. `pytest -q` 全绿（真实 CUDA 缺失的 skip 不计）。

## 失败、负面发现、错误日志
1. **多相索引映射写反**：最初用 `Fraction(dst, src)` 的分子/分母当 (step, phases)，导致 16000→24000 时 `IndexError: index 8032 is out of bounds for axis 0 with size 8032`。正确关系是输出第 n 个样本位于输入位置 `n*src/dst`，即 `step = numerator(Fraction(src,dst))`、`phases = denominator`。修正前该实现连上采样都无法运行，测试捕获。
2. **F0 三倍频下陷（octave-down）**：无偏自相关修正 `ac *= N/(N-lag)` 偏袒长滞后，220 Hz 纯音最初中位数 **73.33 Hz**（=220/3）、400 Hz 中位数 **133.25 Hz**（=400/3），误差 66.7%。修正为“在全局峰值 85% 以内取最短的局部极大滞后”，修正后 219.96 / 399.33 Hz。这条是真实算法缺陷，不是测量噪声；若不复测会静默产生错误音高曲线。
3. **通带指标本身的伪影**：先用峰值 `max|y|` 测增益，4 kHz 得到 **-1.2492 dB**，超过预注册的 0.5 dB。根因不是滤波器衰减，而是 24 kHz 采样下 4 kHz 只有 6 个样本/周期，峰值点与采样点最多差 30°，`20log10(cos30°)=-1.25 dB` 正好吻合。改为整周期 RMS 后为 0.0 dB。原始数值保留于此，指标修正在测试里同样适用（`test_resample_preserves_passband_gain` 用 RMS）。
4. **分段时长虚高**：最初 `end = frames*hop + window`，把 20 ms 点击算成 65 ms，越过 60 ms 下限被当成音节。改为 `frames*hop` 后同一 fixture 为 40 ms 并被丢弃；代价是真实音节的时长略偏短（少算约半个窗）。
5. **已知边界**：15 ms 点击仍会变成 60 ms 段而被保留（正好卡在 `min_segment_s=0.06`）。未修复，记录为已知限制；10 ms 及以下能稳定丢弃并报告。
6. **无真实数据**：AISHELL-3 不在本机，本实验所有数字均来自合成信号；没有任何真实语音上的 F0/分段精度结论，也没有人工听音。

## 结论 / 下次实验
在合成信号上，信号前端满足全部预注册判据：有理数重采样通带平坦、阻带 -87 dB（线性插值对照 -0.34 dB），自相关 F0 误差 <1%，能量分段在干净突发上精确、失败均有 issue。真实语音（连读、弱化、清辅音、呼吸噪声）下的表现未知，必须在拿到语料后重跑 EXP-0005 的测量脚本并把真实统计单独记为后续实验，不能把本实验结论外推。

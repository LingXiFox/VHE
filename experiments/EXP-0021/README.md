# EXP-0021 — Real-corpus check of the chain-HMM aligner (AISHELL-3 subset)

状态：真实语料上的**行为验证**，CPU-only NumPy，无 VHE 训练、无听音、无批量音频生成。
数据只读（WAV 按需解码），未修改原始语料，未提交任何音频。

## 假设
在 AISHELL-3 train split 的 16 个说话人、226 条可渲染句（0.152 h）上训练链式 HMM，
dev split 的 3 个未见说话人、60 条句子上评估：
1. 与能量谷 DP 的音节起点相比，内部边界的 **≥80% 落在 50 ms 内**；
2. **≤10%** 的音素跨度被压到「每状态 1 帧」的地板；
3. Baum-Welch 迭代后**平均跨度置信度高于 flat start**。

判据在运行前写下。任一不成立则该对齐器**不足以驱动配对管线**。

## 变量 / 对照 / 数据划分
- 自变量：Baum-Welch 迭代次数（0 = flat start 对照，2/3/4 = EM）。
- 数据划分：按**说话人**切分，训练用 train split 说话人，评估用 dev split 说话人，无重叠。
- 固定：3 状态/音素、单分量、10 ms 跳、16 kHz、13 MFCC + Δ + ΔΔ、逐句 CMVN、seed 42、
  首尾静音由能量门裁剪（HMM 不建模静音）。
- 参照物：`vhe.data.align.align_syllables`（能量谷 DP）。**它不是 ground truth**，
  本身没有人工边界验证；一致性只能说明两者兼容，不能说明哪一方正确。
- 规模阶梯（同一脚本）：12 条 / 60 条（本机 Apple M5，CPU）、226 条（4090 机器，CPU）。

## 实际结果

|---|---|---|---|---|---|---|---|
| mac12 | 12 | 1697 | 0 | 0.221 / 0.19 / 0.56 | 19.4% | 37.3% | 0.821 |
| mac12 | 12 | 1697 | 2 | 0.127 / 0.09 / 0.22 | 22.6% | 28.4% | 0.806 |
| mac60 | 60 | 8942 | 0 | 0.113 / 0.08 / 0.25 | 32.3% | 14.9% | 0.516 |
| mac60 | 60 | 8942 | 3 | 0.116 / 0.09 / 0.26 | 30.7% | 11.6% | 0.745 |
| 4090 | 226 | 38291 | 0 | 0.146 / 0.10 / 0.32 | 27.9% | 12.4% | 0.489 |
| 4090 | 226 | 38291 | 4 | 0.140 / 0.10 / 0.30 | 30.7% | 5.2% | 0.816 |

## 判据裁定

1. **≥80% 落在 50 ms 内：证伪**（30.7%，三次规模里最高也只有 32.3%）。
2. **≤10% 压到地板：未达成但接近**（5.2%；flat start 为 12.4%）。
3. **EM 提高置信度：通过**（0.489 → 0.816）。

## 失败原因分析

- **边界一致性差不能直接归因于对齐器**：参照物是能量谷 DP，它把音节窗口按能量谷均分到
  语音区间，本身对协同发音、塞音闭塞段无感知。50 ms 判据假设参照物正确，而这个假设
  从未验证。因此第 1 条判据的失败**既可能是对齐器错，也可能是参照物错**，本实验无法区分。
- **可复现的结构性问题（与参照物无关）**：所有音素大类的平均时长都挤在 0.05–0.135 s，
  元音/塞音比值只有 1.43（4 轮 EM），而真实普通话元音通常是塞音的 2–3 倍。原因是转移
  概率被固定为 0.5/0.5：**每个状态期望停留 2 帧**，3 状态音素期望 6 帧 = 60 ms，
  与音素类型无关。数据再多也只能让发射概率去对抗这个先验，改不了先验本身。
- 小规模（12 条）表现方向相反：元音 0.178 s、塞音 0.116 s，但 37% 的音素被压到地板——
  106 个状态只分到 1697 帧（每状态约 16 帧），flat start 分块本身就没有足够帧可分配。
  该配置**不能用于少于数十句的训练**。
- 数据规模效应：12 → 226 条，地板比例 37.3% → 5.2%，但时长分布反而更均匀，进一步支持
  「先验主导、发射不足以表达时长」的判断。

## 结论
- 对齐器在真实语料上**能训练、能收敛、不产生非法跨度**（60 条评估句 0 例问题，没有重叠
  或逆序），但**时长模型有结构性缺陷**：固定自环概率把各音素类的时长压向同一个
  60–130 ms 区间，不足以支撑配对管线里的音素级划分。
- 下一步 EXP-0022：把自环概率改为逐状态从数据重估（Baum-Welch 转移计数 + Beta 平滑），
  预测（运行前写下）：元音/塞音平均时长比值从 1.43 升到 ≥2.0、地板比例 ≤5%、
  置信度不低于 0.80、似然仍单调。
- 与 DP 的一致性不作为 EXP-0022 的通过判据，只作为回归护栏（不得显著变差）。

## 未回答的问题
- 真实边界到底在哪：没有人工标注，也没有可核对的外部对齐。
- 60 条评估句里有 1 例最短跨度 0.4 s（`min_phone_s` 最大值），疑似句内长停顿被塞进单个
  音素；没有逐例复查。
- MPS/CUDA 未被使用（纯 NumPy 路径），本实验与 GPU 无关。
